# HTB HUD

**Author:** DR4V3N1X (Yahya Ouarrak)  
**Version:** 1.2.0  

![HTB HUD Showcase](screenshot.png)

A dark, high-contrast HUD theme for Obsidian inspired by Cyberpunk and Hack The Box aesthetics. Optimized for maximum readability and a seamless terminal-like experience.

---

## ⚙️ Requirements

To fully utilize this theme, you must install the **Style Settings** plugin:
1. Navigate to **Settings** -> **Community Plugins** -> **Browse**.
2. Search for **Style Settings** and install it.
3. Enable the plugin to access the HTB HUD configuration menu.

## 💎 Recommended Plugins

To get the absolute ultimate hacker workstation experience, I highly recommend installing these community plugins alongside the theme:

- **Style Settings:** (Required) Unlocks the massive customization menu for this theme.
- **Shiki Highlighter:** Perfectly syntax-highlights your code blocks using native VSCode themes.
- **Editing Toolbar:** Adds a slick, accessible formatting toolbar to your workspace.
- **Iconize:** Lets you add awesome custom icons to your folders and files.
- **Templater:** For automating your note creation and hacking templates.

---

## ⚙️ Customization

Open the **Style Settings** plugin to customize:
- **Colors:** Modify base HUD colors, backgrounds, and specific H1-H6 heading colors.
- **UI Elements:** Toggle sharp terminal corners or default rounded corners.
- **Animations:** Enable or disable glowing tooltips and ambient workspace animations.

---

## 📥 Installation

### Option 1: Community Themes (Recommended)
1. Open Obsidian **Settings** -> **Appearance**.
2. Click **Manage** under Themes.
3. Search for **HTB HUD** and click **Install and Use**.

### Option 2: Manual Installation
1. Download 	heme.css and manifest.json from this repository.
2. Place both files inside .obsidian/themes/HTB HUD/ in your vault.
3. Go to **Settings** -> **Appearance** and select **HTB HUD**.
